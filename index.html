🚀 Connect Task Tracker to Supabase

This is a one-time setup. You'll need a free Supabase account. Follow the steps below and your app will be ready for multiple users with shared data.

1
Create a free Supabase project
Go to supabase.com → New project. Choose any name and region. Takes ~2 minutes.
2
Run the database setup script
In your Supabase project: SQL Editor → New query. Paste the contents of setup.sql (the file included with this download) and click Run.
3
Get your API credentials
In Supabase: Settings → API. Copy the Project URL and the anon / public key.
4
Paste your credentials below
These are stored only in your browser and in the GitHub repository — never sent anywhere else.
